# 🌐 Minha Primeira Página Web – Ada Lovelace  

Este é o meu primeiro projeto de página web, criado como parte dos meus estudos em *HTML, CSS e JavaScript*.  
A página é dedicada a *Ada Lovelace*, considerada a primeira programadora da história e uma das maiores mulheres que contribuíram para o avanço da tecnologia.  

## 📖 Sobre o Projeto  
A página apresenta:  
- Um *design colorido e responsivo*, feito com HTML e CSS.  
- Informações sobre a vida de Ada Lovelace (infância, juventude e vida adulta).  
- Imagens históricas.  
- Links para conhecer outras mulheres que fizeram história na tecnologia.  
- Um formulário simples para interação.  

## 🚀 Tecnologias Utilizadas  
- *HTML5* → estrutura da página  
- *CSS3* → estilização e cores  
- *JavaScript* → (para futuras interatividades)
